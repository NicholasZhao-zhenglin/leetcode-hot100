# LeetCode 热题 100 · 算法手册

从 PDF 整理的离线题解网页，包含 17 个算法分类和完整 100 道题。

## 功能

- 分类目录、题目搜索、难度筛选和上一题／下一题跳转
- 题目描述、解题思路、Python 参考代码、复杂度分析和核心知识点
- 代码高亮与一键复制
- 收藏和学习进度，保存在当前浏览器
- 浅色／深色模式，适配电脑和手机
- 可跳转到原始 PDF 对应页
- **刷题熟练度评估**：每题可标记 A 熟练 / B 基本掌握 / C 掌握薄弱 / D 未掌握（默认为「未评估」）
- **刷题历史记录**：一键记录当天刷题、补录历史日期、编辑备注与评级、删除误操作；同一天可记录多次
- **智能复习提醒**：按最近一次刷题日期与当前熟练度推算复习时间（A 不安排 / B 7 天 / C 3 天 / D 1 天），到期显示「待复习」并可一键筛选
- **学习统计**：熟练度分布、已评估题数、待复习题数、累计刷题次数、近 7 天与近 30 天刷题量
- **数据备份**：学习记录可导出为 JSON 并重新导入，避免浏览器数据被清理后丢失

## 使用

直接用浏览器打开 `index.html` 即可离线阅读，无需安装依赖。

在线浏览：[LeetCode 热题 100 网页版](https://nicholaszhao-zhenglin.github.io/leetcode-hot100/)

## 刷题熟练度与复习管理

在题目详情页底部（「理解之后，再独立写一遍」之后）有三个区域：

1. **刷题熟练度** — 点选 `未评估 / A 熟练 / B 基本掌握 / C 掌握薄弱 / D 未掌握` 即可落库，
   随时可改；它与原来的「已掌握」开关互不影响。
2. **记录一次刷题** — 一键记录当前时间；「补录历史日期」可选任意过去日期（会标注「补」），
   并为该次记录选评级、写备注（例如「滑动窗口边界条件处理不熟练」）。
3. **刷题历史** — 按时间倒序展示，可编辑或删除；删除需点两次确认。

复习日期 = 最近一次刷题日期 + 当前熟练度对应的间隔。若某题只设了熟练度、从没有刷题记录，
不会虚构日期，会提示先记录首次刷题。

目录页顶部新增「学习统计」面板，筛选栏新增「待复习」标签与熟练度筛选；侧栏底部在有待复习题时
会出现直达入口。

## 数据存储

学习记录全部保存在浏览器 localStorage，分两个键：

| 键 | 内容 |
| --- | --- |
| `leetcode100-reading-v1` | 完成状态、收藏、上次阅读、主题（原有） |
| `leetcode100-practice-v1` | 熟练度、刷题历史（本次新增） |

两个键相互独立：新字段不会写进旧键，旧数据也不会因为升级丢失。旧题目一律显示为「未评估」，
不会因为原来标记过「已掌握」就推断为 A。统计面板右上角提供「导出记录 / 导入记录」，
导入采用合并策略（完成与收藏取并集、刷题记录按 id 去重），不会覆盖本地已有数据。

## 文件

- `index.html`：完整网页，已内嵌样式、脚本和题解数据
- `LeetCode热题100分类题解（完整100题）.pdf`：原始题解文档
- `.nojekyll`：按静态文件发布，无需构建

网页内容依据原 PDF 保留；题目名称与题号对应 LeetCode。学习记录不会上传到仓库，也不会在不同设备间自动同步。
